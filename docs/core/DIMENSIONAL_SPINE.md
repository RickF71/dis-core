# DIS Dimensional Spine (v1)
This document defines the canonical dimensional spine of the DIS ontology.
Each layer represents a totelevation from the previous one.

0D: Execution Core
  - Pure runtime/executor
  - Immutable
  - Cannot contain policy
  - Cannot be modified by any domain

1D: null — First Policy Layer
  - First dimensional expression of law
  - Applies the first policy to running 0D execution
  - All domains descend from null

2D: aether — Directional Field
  - First directional propagation
  - Allows linear coherence

3D: terra — Coherence Surface
  - Enables stable life fields
  - Adds planar coherence rules

4D: numan — Volumetric Life
  - Embodied, 3D life
  - Structure for organisms and bodies

5D: lima — Agency / Meaning
  - Symbolic cognition
  - Intentionality
  - Social/relational meaning

6D: corporeal — Sovereign Identity
  - Full individuated self-domain
  - Root of personal sovereignty

All domains inherit the spine definition but may only override non-0D layers.
