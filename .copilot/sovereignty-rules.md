# Sovereignty Rules — Copilot Guidance

A domain is sovereign over its own subtree because it holds the PSeat
for that branch.

Copilot should ensure:

- Domain-centric authority, never global
- Capabilities propagate downward from ancestors
- Ancestor denials override descendant declarations
- A corporeal domain can do anything it is capable of within its subtree
- No domain may modify ancestor policies
- Capability merging happens strictly in the loader
- Domain loader = sovereignty engine

This aligns with DIS principles:
"A domain should only need itself to govern itself."
